# ToDoList JS

Приложение для управления повседневными задачами.

## Стек

- HTML5
- CSS3
- JavaScript
- Vitest

## Возможности

- Создание задач
- Редактирование задач
- Удаление задач
- Валидация данных
- Проверка дубликатов

## Запуск

Откройте index.html в браузере.

## Тестирование

npm install
npm test
